# Security and data-safety reports

If you discover a way for Klearspace to target an unintended location, bypass selection/protection rules, overwrite files during restore, or expose personal data, stop using the affected operation.

Use the repository's private [Report a vulnerability](https://github.com/kunal-shekte/klearspace/security/advisories/new) form for sensitive details. Do not publish exploit details, credentials, or private filesystem paths in a public issue. Non-sensitive bugs can use GitHub Issues with redacted paths and reproducible test fixtures.

The project currently maintains the latest release. Reports are handled on a best-effort basis; there is no guaranteed response or remediation timeframe.

The v1.1.0 downloadable app is ad-hoc signed and not Apple-notarized. Verify the source and release checksum before deciding to run a downloaded build. See the [installation guide](docs/INSTALLATION.md).
