# Changelog

## 1.1.0 — 2026-10-17

- Renamed the application and Swift packages to **Klearspace**.
- Added System, Light, and Dark appearance options with persistent preferences. System is the initial default.
- Added adaptive colors for the dashboard, sidebar, results, notices, settings, and cleanup review.
- Published the project under the MIT license with installation, usage, safety, and contribution guides.
- Added a reproducible DMG packaging script, architecture-specific downloads, checksums, and macOS CI.
- Preserved visual scanning, reviewed batch cleanup, protected shared containers, and Trash recovery.

## Clearspace preview

Initial local prototype, prior to the public Klearspace repository. This preview was not a GitHub release. Its application identifier and local state are separate from Klearspace.
